# Semana 01 — Marco teórico y problema de investigación

Esta carpeta contiene la documentación académica versionable correspondiente a la **Semana 01** del proyecto del curso **Curso Integrador I: Sistemas Software**.

El proyecto ha sido reorientado hacia el **Hospital de Huaycán — MINSA / DIRIS Lima Este** como caso de estudio propuesto. El diagnóstico institucional específico continúa **pendiente de validación docente y levantamiento en campo**.

## Objetivo de la entrega

Elaborar y sustentar el marco teórico del proyecto de software mediante antecedentes académicos relacionados con:

- gestión de citas médicas;
- sistemas web y móviles de reserva;
- tiempos de espera;
- calidad de atención;
- no-show e inasistencias;
- cancelaciones y reprogramaciones;
- disponibilidad y aprovechamiento de agenda;
- adopción, usabilidad, privacidad e integración.

A partir de esta revisión se formula un **problema de investigación preliminar** orientado al diseño de una plataforma web y móvil para la gestión de citas médicas y la trazabilidad del flujo de consulta externa del Hospital de Huaycán.

## Caso de estudio

**Hospital de Huaycán — MINSA / DIRIS Lima Este.**

Estado:

**PROPUESTO / PENDIENTE DE VALIDACIÓN FINAL CON EL DOCENTE.**

La propuesta toma como referencia:

- procesos de consulta externa;
- gestión de citas médicas;
- admisión y archivo;
- flujo ambulatorio;
- futura infraestructura hospitalaria;
- iniciativas institucionales relacionadas con tiempos y atención.

El proyecto es académico y no representa una solución oficial del Hospital de Huaycán, MINSA, DIRIS Lima Este o PRONIS.

## Línea de investigación actual

La propuesta se orienta a una **plataforma web y móvil para la gestión de citas médicas y la trazabilidad del flujo de consulta externa**.

Capacidades de interés del proyecto:

- consulta de especialidades y disponibilidad;
- reserva;
- confirmación anticipada;
- cancelación;
- reprogramación;
- recordatorios;
- recuperación de cupos;
- lista de espera;
- ofertas de cupos liberados;
- priorización ambulatoria validada por personal autorizado;
- check-in;
- admisión;
- triaje como estado operativo cuando corresponda;
- espera y llamado;
- finalización de la atención;
- métricas y auditoría;
- accesibilidad web y móvil.

Estas capacidades forman parte del alcance propuesto del proyecto, pero las reglas institucionales exactas deben validarse antes de considerarlas definitivas.

## Decisiones académicas

- Se utiliza **APA 7** como norma de referencia.
- Hernández Sampieri et al. (2014) se utiliza como fuente metodológica, no como antecedente.
- Los antecedentes principales y complementarios deben mantenerse diferenciados.
- Las fuentes institucionales no sustituyen la evidencia académica.
- No se trasladan porcentajes o resultados de otros hospitales como si fueran datos de Huaycán.
- No se aceptan referencias cuya autoría, título, DOI, handle o URL no puedan verificarse.
- El diagnóstico específico del Hospital de Huaycán permanece pendiente de levantamiento.
- No se adelantan hipótesis, muestra, instrumentos ni diseño experimental definitivo.
- Se utilizarán datos sintéticos durante el desarrollo académico.
- No se recopilarán historias clínicas reales ni datos personales identificables sin autorización.
